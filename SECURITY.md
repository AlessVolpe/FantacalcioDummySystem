# Security policy

## Supported versions

Fantacalcio Dummy System is in early development and does not yet provide a
stable, production-ready release. Security fixes target the current `main`
branch; older development snapshots are not maintained independently. This
policy will be revised when supported release lines are established.

## Reporting a vulnerability

Use GitHub's [private vulnerability reporting form](https://github.com/AlessVolpe/FantacalcioDummySystem/security/advisories/new).
Alternatively, open the repository's **Security** tab, select **Advisories**
and choose **Report a vulnerability**. Repository administrators must enable
private vulnerability reporting for this channel to be available.

Do not open public issues or pull requests for undisclosed vulnerabilities.
Include the affected revision, environment, a description of the issue,
impact, safe reproduction steps and any suggested mitigation. Redact secrets,
credentials and personal data. Do not access data or systems without permission.

The maintainer will assess reports as availability permits, coordinate fixes
and disclosure with reporters, and avoid publishing sensitive information.
No fixed response or remediation SLA is promised at this development stage.

For vulnerabilities in the native engine itself, consult the
[Central Ranking Dogma repository](https://github.com/AlessVolpe/CentralRankingDogma/security).
