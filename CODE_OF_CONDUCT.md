# Code of Conduct

## Adopted standard

Fantacalcio Dummy System adopts the [Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/)
in full by reference, including its pledge, encouraged and restricted behaviors,
scope, reporting principles and graduated enforcement framework. The linked
version is the applicable standard, not an automatically changing policy.

## Project-specific reporting and enforcement

The repository maintainer, [@AlessVolpe](https://github.com/AlessVolpe), is
responsible for moderation in project spaces. Report abuse on GitHub using
its [reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam),
which allow confidential platform reports. For project-specific concerns,
contact the maintainer privately through a contact method they make available
on their GitHub profile. A dedicated confidential project reporting address has
not yet been established; do not disclose sensitive incident details publicly.
If the concern involves the maintainer, use GitHub's reporting tools directly.

The maintainer will handle reports with discretion, protect the privacy of the
people involved to the extent possible, and apply the Covenant's enforcement
framework proportionately. GitHub's own policies and reporting processes also
apply. Security vulnerability reports are handled separately under
[SECURITY.md](SECURITY.md).
